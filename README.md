# 原稿用紙 — 600字の横書きエディタ

20字 × 30行、1枚600マスのシンプルな日本語エディタです。iPad・スマートフォン・PCのブラウザーで使えます。

**使う → https://sirokun1265.github.io/genko-editor-600/**

## 使い方

- タイトルと本文を入力すると、原稿用紙に1文字ずつ反映します。
- 600マスを超えると自動的に次の用紙へ進みます。改行は次の行へ進みます。
- 「一般的な原稿用紙」では、行頭へはみ出す句読点・閉じ括弧を前行の最後の文字と同じマスに置きます。「。」と直後の閉じ括弧も1マスにします。開き括弧が行末で中身と離れないよう次行へ送ります。
- 小さい「っ・ゃ・ゅ・ょ」、長音「ー」、絵文字も1字で1マスです。小さい仮名や長音を行頭から強制移動しません。
- 「書式の設定」で、半角数字・英小文字を2字で1マスにする設定（初期値オン）と、段落の自動字下げ（初期値オフ）を選べます。すでに空白のある段落と「『で始まる段落は追加で下げません。
- 三点リーダー・ダッシュの2字一組を行の途中で分割しません。単独の記号、手動改行直後の句読点、用紙の最終マスへの追い込みなどは確認メッセージを表示します。
- 学校や試験で必ず1マス1字と指定されている場合は「1マス1字（禁則なし）」を選べます。手動改行はどちらの設定でも維持します。
- 字数は入力本文の改行を除いて数えます。空白・句読点・括弧も含み、同じマスにまとめても入力字数は減りません。入力字数と使用マス数は異なります。
- 書式設定はプレビューと印刷に適用します。入力本文・ダウンロードするテキストは変更しません。題名欄はマス外の見出しです。題名・氏名をマス内に書く必要があれば、本文に含めて調整してください。
- iPadなどの狭い画面では「書く」「原稿用紙」で表示を切り替えます。
- 「テキスト保存」でUTF-8の `.txt` ファイルを保存できます。タイトルはファイル名になります。
- 「開く」でUTF-8のテキストファイルを読み込めます。
- 「印刷」で全ページをA4で印刷できます。ブラウザーの印刷画面からPDF保存もできます。
- iPadのSafariでは共有メニューの「ホーム画面に追加」でアプリのように起動できます。初回と再読み込み時にはインターネット接続が必要です。

原稿は端末のブラウザー内（localStorage）に保存されます。端末間の同期はありません。ブラウザーのデータ削除で消えるため、大事な文章はテキストファイルにも保存してください。原稿本文をサーバーやGitHubに送る処理はありません。

原稿用紙の細則は提出先ごとに異なります。学校・試験・応募要項の指定を優先してください。調査根拠とこのエディタの扱いは [RULES.md](RULES.md) に記載しています。

## 開発

フレームワーク・外部ライブラリー・ビルドは不要です。Node.js 20以上で次を実行します。

```sh
npm start
npm test
```

ローカルURL: http://127.0.0.1:4173

GitHub Pagesは `main` ブランチのルート `/` を公開します。`.nojekyll` により静的ファイルをそのまま配信します。

CSS・アプリ・レイアウトモジュールは同じ `?v=` の版番号で読み込みます。更新時には `index.html` 内のCSS・アプリのURLと、`app.js` 内の `manuscript.js` のURLをまとめて更新してください。初期版のモジュールがブラウザーに残っても描画を停止しない互換処理があります。読み込み失敗時にも用紙の罫線と再読み込みの案内を表示します。
